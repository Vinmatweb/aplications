# Etsy PDF balíčky – Claude

Samostatná HTML verze aplikace z dodaného souboru `etsy-pdf-balicky.html`. Publikovaným vstupním souborem je `index.html`; jeho obsah je zachován beze změn.

Web: https://vinmat.eu/aplications/pdf2etsy-v2/

Zdroj: https://github.com/Vinmatweb/aplications/tree/main/pdf2etsy-claude

## Publikování

Aplikace nevyžaduje sestavení. Soubor `index.html` je publikovaný v repozitáři `Vinmatweb/vinmatweb.github.io` pod cestou `aplications/pdf2etsy-v2/index.html` přes GitHub Pages.

PDF knihovny se načítají z cdnjs a písmo z Google Fonts. Projekty a nastavení se ukládají do prohlížeče. Přímé připojení Google Drive vyžaduje vlastní OAuth Client ID; pro webovou verzi je potřeba povolit původ `https://vinmat.eu`.
