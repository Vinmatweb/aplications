Google Drive
Hlavní složka = složka, ve které je podsložka pro každé zvíře (Irbis, Buvol, Lemur…). Jednorázové nastavení:
  1. console.cloud.google.com → nový projekt → APIs & Services → Library → zapni Google Drive API.
  2. OAuth consent screen → External → vyplň název, svůj e-mail a přidej se jako test user.
  3. Credentials → Create credentials → OAuth client ID → typ Web application → do Authorized JavaScript origins dej http://localhost:8765.
  4. Client ID vlož sem. Aplikaci pak spouštěj přes spustit.bat (Drive nefunguje při otevření souboru dvojklikem).
Bez nastavování: použij 📂 Lokální složka a vyber složku z Google Drive pro počítač (disk G:) – funguje stejně.
