# Applications

Repository for VinMat utility applications. Each application lives in its own folder.

## bgmusic — YouTube Music Library
Tracks AI background-music prompts and downloaded YouTube Audio Library tracks by LEGO theme/subtheme.

Public URL: https://vinmat.eu/aplications/bgmusic/

Development files: `bgmusic/`

Progress is stored in browser localStorage and can be backed up/restored using JSON export/import.

## dchs — Family transport statistics
Mobile-first weekly tracker for school and kindergarten trips, pickups, clubs and weekend activities.

Public URL: https://vinmat.eu/aplications/dchs/

Development files: `dchs/`

Family entries stay in the browser's localStorage and are never committed to GitHub.

## ideas-and-priorities — Ideas & Priorities
Mobile-friendly ranked board for active work and unsorted ideas, with importance levels, drag-and-drop sorting, Czech voice input, and local backup/restore.

Public URL: https://vinmat.eu/aplications/ideas-and-priorities/

Development files: `ideas-and-priorities/`

The board is stored in the browser's localStorage and can be backed up/restored using JSON export/import.

## ollie-classroom — Ollie's Classroom
English practice activities with Ollie the owl for young learners.

Public URL: https://vinmat.eu/aplications/ollie-classroom/

Development files: `ollie-classroom/`
