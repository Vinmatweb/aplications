# VinMat’s World: Ideas & Priorities

A small, mobile-friendly board for sorting active work from ideas that can wait.

## Included

- Add, rename, and remove priorities or ideas.
- Reorder either list with drag and drop or the up/down controls.
- Move an idea into Priorities; it starts at Medium importance and can be changed to High, Medium, or Low.
- Move a priority back to Ideas.
- Dictate in Czech when the browser supports speech recognition.
- Automatically save in the current browser, with JSON export and restore for backups.

The board is stored in browser `localStorage`. It does not sync between devices. Export a backup before switching browsers or devices.

## Run locally

Open `index.html` in a browser. The app has no build step or runtime dependencies.
